# Personal Toolbox

A collection of tools for teaching and admin tasks.

## Tools

| Tool | What it does | 
|------|---------------|
| [asset_checker](./asset_checker/) | Checks URLs in a LibGuides asset HTML export and flags broken links. |
| [bookmark_checker](./bookmark_checker/) | Checks exported bookmarks for dead links and builds a cleaned bookmark file for browser re-import. |
| [combine_md](./combine_md/) | Combines date-named Markdown notes in each subfolder into a single ordered `combined.md` file. |
| [html2md](./html2md/) | Converts Canvas textbox-export HTML files into Markdown notes and places them in matching student folders. |
| [image_scraper](./image_scraper/) | Scrapes images from a webpage, downloads them, and records filenames with alt text. |
| [student_folders](./student_folders/) | Creates filesystem-safe student folders from a roster CSV using `firstname_lastname` naming. |
| [tutorial_builder](./tutorial_builder/) | Turns a narrated screen recording into an editable step-by-step tutorial with pictures, a transcript and captions. |
| [tutorial_presenter](./tutorial_presenter/) | A bookmark that spotlights, zooms and steps through any tutorial web page while teaching. |
