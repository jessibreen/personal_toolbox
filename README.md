A small Python project that checks an .html of bookmarks for dead links and produces a clean bookmark file ready to import into any browser.

## What It Does

1. **Checks** every URL to see if it's alive or dead
2. **Generates** a .csv of all links with their status and a .csv of dead links with Wayback Machine URLs for recovery.
3. **Produces** a clean bookmark file with dead links removed ready to be imported to a browser.

## Files

| File                       | Description                                                       |
| -------------------------- | ----------------------------------------------------------------- |
| `dirty_bookmarks.html`     | Your bookmarks list from your browser (input)                     |
| `check_bookmarks.py`       | Checks all URLs for dead links                                    |
| `build_clean_bookmarks.py` | Builds a clean bookmark file from the report                      |
| `bookmark_report.csv`      | Full results for every URL (generated by checker)                 |
| `dead_links.csv`           | Dead links only, with Wayback Machine URLs (generated by checker) |
| `bookmarks_clean.html`     | Final clean bookmark file ready to import (generated by builder)  |

## Setup

```bash
# Navigate to the project folder
cd path/to/project

# Create the virtual environment
python -m venv .venv

# Activate it
source .venv/bin/activate

# Install the one dependency
pip install requests
```

## Usage

### Step 1 — Check for dead links
```bash
source .venv/bin/activate
python check_bookmarks.py
```
This will take a few minutes to run through all URLs. Progress prints to the terminal as it goes. Results are saved continuously so progress isn't lost if interrupted.

### Step 2 — Review dead links
Open `dead_links.csv` in Excel or Numbers. Each dead link includes a `wayback_url` column — click it to see if an archived version exists on the Wayback Machine.

If you want to **rescue** a link (i.e. keep it in your bookmarks even though it's dead), change its `dead` value from `YES` to `no` in `bookmark_report.csv` before running Step 3.

### Step 3 — Build the clean bookmark file
```bash
python build_clean_bookmarks.py
```
Produces `bookmarks_clean.html` with all dead links removed and empty folders cleaned up.

### Step 4 — Import into your browser
In Firefox: **Bookmarks menu → Manage Bookmarks → Import and Backup → Import Bookmarks from HTML**

The output file is standard Netscape bookmark format and is compatible with all major browsers.

## Notes

- To deactivate the virtual environment when done: `deactivate`
- The checker uses 20 parallel threads by default — this can be adjusted with the `MAX_WORKERS` setting at the top of `check_bookmarks.py`
- Timeout per URL is 10 seconds, also adjustable at the top of the script
- Python version: 3.12.3 (pyenv)
