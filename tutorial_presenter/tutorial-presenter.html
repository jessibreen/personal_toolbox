For teaching from a tutorial page

Tutorial Presenter

Spotlight, zoom and step through any tutorial page while you teach. It runs from a bookmark, so the tutorial file stays exactly as you exported it.

Set it up once

  1. Show your bookmarks bar. In Chrome press ⌘ Shift B. In Safari choose View, then Show Favorites Bar.

  2. Drag this button onto the bar.

    Present Drag it up to the bar. Don't click it.

    Dragging not working? then add a new bookmark by hand and paste the code in as its address.

  3. Open a tutorial and click the bookmark. Click it again, or press Q, to turn it off.

Recording a quick video

Useful when a student asks about one step: spotlight and zoom through it while you talk, and send them the video.

  1. Press R, or click the faint Record button in the bottom right corner.
  2. The browser asks what to share. Pick this tab to record just the tutorial, or Entire screen if you want to switch to QGIS during the video. Then allow the microphone.
  3. Talk through it as you would in class. Press M to mute for a moment if you need to.
  4. Press R again or click Stop. The video lands in your Downloads folder, named after the tutorial and the date, ready to upload to Canvas.

Chrome and Safari save an MP4, which plays in QuickTime and uploads to Canvas. Firefox can only save WebM videos, which Canvas doesn't accept, so in Firefox the Record button explains how to use your Mac's own recorder instead (⌘ Shift 5, with your microphone picked under Options). To record your entire screen or another app, a Mac first asks you to allow screen recording for your browser in System Settings, under Privacy & Security. Recordings stay on your computer until you upload them.

Good to know

  • Scrolling still works. Use the trackpad, mouse wheel or the up and down arrow keys, including while zoomed in.
  • Links are paused while the presenter is on, so a stray click can't take you off the page. Hold ⌘ and click to follow one.
  • Inside Canvas it may not reach the tutorial. Canvas usually shows an uploaded page inside a frame, which a bookmark can't get into. The presenter will offer to open the tutorial in its own tab. Opening your exported file straight in the browser always works.
  • Nothing is saved or sent anywhere. Highlights and spotlights disappear when you quit or reload, and the page is left as it was.

Sample tutorial to practise on

This is a short made-up example, not one of your tutorials.

Which homes sit within 30 metres of a stream?

You have two layers: the streams in a county and the homes in it. The goal is a list of homes that fall inside a 30 metre strip on either side of any stream.

LayerGeometryUsed for
streamsLinesThe features we measure distance from
homesPointsThe features we want to pick out

The workflow

Step 1. Put the streams in a projection that uses metres

  1. Open Vector, then Data Management Tools, then Reproject Layer.
  2. Set Input layer to streams.
  3. Set Target CRS to a projected system measured in metres, such as the UTM zone for your area.
  4. Run the tool and name the result streams_utm.

Why this comes first. Buffer measures distance in the layer's own units. In a geographic coordinate system those units are degrees, so a distance of 30 would mean 30 degrees, not 30 metres.

Step 2. Buffer the streams

  1. Open Vector, then Geoprocessing Tools, then Buffer.
  2. Set Input layer to streams_utm and Distance to 30 metres.
  3. Tick Dissolve result so overlapping strips merge into one shape.
    • Without it you get one buffer per stream segment.
    • With it, a home near two streams is only counted once.
  4. Run the tool and name the result stream_buffer.

Step 3. Select the homes that fall inside the buffer

  1. Open Vector, then Research Tools, then Select by Location.
  2. Set Select features from to homes.
  3. Under Where the features, tick intersect.
  4. Set By comparing to the features from to stream_buffer, then run the tool.

The selected homes are your answer. Open the attribute table and switch it to show selected features to see the list.
